# TaxMitra 🏦
### AI-Powered CA Assistant for Indian Small Businesses

**Live Demo:** https://taxmitra-257248616047.us-central1.run.app

## What is TaxMitra?
TaxMitra is an AI-powered Chartered Accountant assistant built for India's 63 million small businesses. It provides instant GST, ITR, TDS, and tax compliance guidance in Hindi and English — at just ₹299/month instead of ₹5,000-20,000/month CA fees.

## Tech Stack
- **AI:** Google Gemini 2.5 Flash (Vertex AI)
- **Backend:** Python Flask
- **Deployment:** Google Cloud Run
- **Payments:** Razorpay (coming soon)

## Features
- GST Registration & Filing guidance
- ITR Filing help
- TDS calculations
- Tax saving strategies
- Compliance deadline reminders
- Hindi & English support
- 24/7 availability
